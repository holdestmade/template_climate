# Brand icon

Brand assets for the **Template Climate** integration — the icon shown next to
*Template Climate* in **Settings → Devices & services → Helpers → Create
helper**, and on the integration/device pages.

## Files

| File | Size | Notes |
| --- | --- | --- |
| `icon.png` | 256×256 | Standard resolution, transparent PNG |
| `icon@2x.png` | 512×512 | hDPI, transparent PNG |

A plain thermometer glyph with no third-party trademarks. Replace it with your
own artwork any time if you prefer.

These are staged here so they're ready to drop into whichever brand location you
use (a local brand folder, or a PR to
[`home-assistant/brands`](https://github.com/home-assistant/brands) under
`custom_integrations/template_climate/`).
